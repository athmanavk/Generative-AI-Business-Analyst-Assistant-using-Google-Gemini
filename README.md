# Generative-AI-Business-Analyst-Assistant-using-Google-Gemini
A Generative AI-powered assistant using Gemini, Python, and Pandas to understand natural-language business questions, analyze sales, profit, categories, and trends, perform automated calculations, generate business insights, and create interactive visualizations for data-driven decision-making.

## 🚀 Project Overview

The AI Business Analyst Assistant combines **Generative AI and Data Analytics** to make business data analysis easier and more interactive.

Instead of manually writing Python or SQL queries, users can simply ask questions such as:

- What is the total sales?
- Which category has the highest sales?
- What is the total profit?
- Which region performs best?
- Show the sales trend.
- Which products generate the most revenue?

The assistant analyzes the available dataset and returns an understandable answer along with relevant business insights.

## ✨ Key Features

- 🤖 Natural-language question answering
